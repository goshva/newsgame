Пять игр к новостям пяти регионов

Сохранить локально пять реальных новостных страниц, сделать к каждой короткую HTML5-игру и встроить её одной вставкой кода. Цель — показать, что игра живёт в изолированном iframe и не ломает сайт издателя.

Дата: 29.09.2026Этап: технический PoCРегионы: US · СНГ · IN · CN · EU

01Что нужно сделать

  1. Сохранить локально пять страниц новостей из таблицы ниже.
  2. Сделать по каждой новости короткую HTML5-игру на 1–3 минуты.
  3. Сделать общий loader-скрипт виджета и встроить его в каждую сохранённую страницу одной вставкой после текста статьи.
  4. Поднять локальный стенд, где страницы и игры отдаются с разных origin, и проверить критерии приёмки из раздела 7.

04Сохранение и встраивание

Сохранение страницы

  1. Откройте новость в Chrome или Firefox. Закройте cookie-баннер, не принимая рекламные cookies.
  2. Сохраните страницу одним HTML-файлом через расширение SingleFile. Если вёрстка ломается, используйте «Сохранить как → Веб-страница полностью». Для статичных страниц подойдёт wget: 
    wget -E -H -k -K -p -e robots=off <url>
  3. Положите результат в pages/<region>/index.html, где region — us, cis, in, cn или eu.
  4. Удалите рекламные, аналитические и трекинговые скрипты (GTM, рекламные SDK, пиксели), чтобы стенд не слал события на реальные сайты. Вёрстку и стили оставьте. Список удалённого запишите в pages/<region>/NOTES.md.
  5. Добавьте в <head> строку <meta name="robots" content="noindex">.
  6. Сделайте скриншот исходной страницы: pages/<region>/before.png.
Только для внутреннего демо. Права на контент страниц принадлежат изданиям. Локальные копии не публикуйте и не кладите в открытый репозиторий.

Встраивание

Сразу после последнего абзаца статьи, до комментариев и рекомендаций, вставьте только этот фрагмент:

<div class="news-game"
     data-placement="article-end"
     data-article-id="us-elias-2-24b"
     data-lang="en"></div>
<script async src="http://localhost:8081/widget/v1.js" data-site="demo-us"></script>

05Технические требования

Структура репозитория

pages/<region>/index.html   копии страниц        (origin A: localhost:8080)
widget/v1.js                loader               (origin B: localhost:8081)
games/<article-id>/         игры                 (origin B: localhost:8081)
  index.html
  game.json                 контент и факты с источниками
  assets/
catalog.json                article-id → игра, язык, срок актуальности, enabled

Страницы и игры отдаются с разных origin, чтобы изоляция iframe проверялась по-настоящему. Оба сервера поднимаются одной командой (npm run dev или аналог).

Loader — widget/v1.js

  • Vanilla JS без зависимостей, не больше 30 KB gzip (цель — меньше 10 KB). Подключается с async и не блокирует рендер.
  • Находит все .news-game, читает data-атрибуты и запрашивает catalog.json. Если игры нет, она просрочена или выключена, контейнер остаётся скрытым без сдвига вёрстки.
  • Показывает компактный тизер «Сыграть по теме» на языке data-lang, когда блок подходит к области просмотра (IntersectionObserver). Iframe создаётся только по клику.
  • Iframe: sandbox="allow-scripts" без allow-same-origin, allow-top-navigation и allow-popups; loading="lazy", referrerpolicy="no-referrer", title. Каждое дополнительное разрешение обосновать в README.
  • Высота iframe меняется по сообщению resize, максимум 90vh; ширина — 100 % контейнера.
  • Стили изолированы через Shadow DOM или префикс. Loader не трогает глобальные стили, window, историю и URL, не перехватывает скролл.
  • При ошибке сети, таймауте 5 с или сообщении error блок сворачивается, в консоль пишется одно предупреждение, других эффектов нет.
  • Kill switch: enabled: false у игры или сайта в catalog.json скрывает блок.

Протокол postMessage v1

{ ns: "newsgame", v: 1,
  type: "ready" | "resize" | "start" | "complete" | "error" | "exit",
  gameId: "us-elias-2-24b",
  sessionId: "<случайный uuid на запуск>",
  payload: {} }
  • Loader принимает сообщения только от origin игр и только от своего iframe.contentWindow; неизвестные ns, v и type игнорирует.
  • Игра шлёт сообщения только в parent с явным targetOrigin, который получает параметром URL и сверяет с allowlist. От страницы принимает только pause и resume.
  • События (запрос конфигурации, видимость, запуск, завершение, результат, ошибка, выход) loader выводит в console.table и отправляет на POST localhost:8081/events (можно писать в JSON-файл). Ответы пользователя и персональные данные не собираются. Флаг preview=1 помечает события как тестовые.

Игры

  • HTML5 + vanilla JS/TS, при необходимости Canvas. Тяжёлые движки — только по согласованию и в рамках бюджета.
  • Начальная загрузка не больше 500 KB gzip (Индия — не больше 250 KB). Внешних запросов нет, все ресурсы локальные.
  • Тексты и факты берутся из game.json, в код не прописываются: 
    { "id": "...", "text": "...",
  "quote": "<дословная цитата из статьи>",
  "source": "<URL статьи>" }
  • Адаптивность от 320 px до desktop; управление касанием, мышью и клавиатурой.
  • Видимый focus, aria-label, контраст WCAG AA, масштабирование текста до 200 %, prefers-reduced-motion; звук выключен по умолчанию, игра работает без звука.
  • Пауза, перезапуск и всегда видимая кнопка «Вернуться к статье», которая отправляет exit.
  • Без регистрации, cookies, localStorage и персональных данных. Игра работает, даже если storage недоступен.
  • Отдельные экраны загрузки и ошибки; ошибка отправляет error.

Браузеры

Последние стабильные Chrome, Safari (iOS и macOS), Firefox, Edge, Chrome на Android. Для Китая дополнительно WeChat in-app browser или эмуляция мобильного Chrome с заблокированными Google-доменами.

07Критерии приёмки

  • В HTML каждой страницы добавлен только фрагмент из раздела 4, других правок для работы виджета нет.
  • Если остановить сервер :8081, страницы открываются без ошибок в вёрстке, а блок игры не виден.
  • Если выставить enabled: false в catalog.json, блок исчезает без правки страниц.
  • Игра загружается только после клика, в iframe с другого origin; из игры нет доступа к parent.document.
  • CLS страницы после вставки вырос не больше чем на 0,01; loader не даёт long task дольше 50 мс.
  • Каждая игра проходится за 1–3 минуты на телефоне и на desktop, работает с клавиатуры, без звука и при prefers-reduced-motion.
  • Все события из протокола видны в логе с sessionId и gameId; персональные данные не собираются.
  • Все факты в играх совпадают с текстом статей; у каждого есть цитата и ссылка.
  • Игра для Китая не делает ни одного запроса за пределы localhost.
